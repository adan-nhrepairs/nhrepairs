## ABOUT CALL-ONLY ADS IN MICROSOFT ADS

**Key specs:**
- Display only on mobile devices (smartphones)
- No landing page click — the ad directly initiates a phone call
- Phone number is the primary visual element
- Character limits: Business Name (25), Phone (auto-filled), Description Line 1 (90 chars), Description Line 2 (90 chars), Display URL (35 chars)
- Must use a verified Microsoft forwarding number
- Ad format in Microsoft Ads: **Call Ad** (found under Responsive search ad creation → toggle to Call Ad)

**Phone number to use:** Your Microsoft Ads forwarding number (set up in Task 0)
**Business Name:** NH Repairs
**Display URL:** nhrepairs.com

## HOW TO SET UP CALL ADS IN MICROSOFT ADS EDITOR

1. In the campaign, go to **Ad Groups → [Select Ad Group]**
2. Click **Ads → Add Ad → Call Ad**
3. Fill in:
   - **Business Name:** NH Repairs
   - **Phone Number:** Select your Microsoft forwarding number
   - **Description 1:** [paste from above]
   - **Description 2:** [paste from above]
   - **Display URL:** [from above]
   - **Final URL:** Not required for call ads — leave blank or use nhrepairs.com
4. Save and repeat for each ad group

**Note:** Call ads compete alongside your responsive search ads. Microsoft will show the format most likely to drive your target action (calls) based on the user's device and query.
